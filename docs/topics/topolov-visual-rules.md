# Тополов. Правила визуальной диагностики психотипов по геометрии лица

> **Назначение документа.** Формализовать описательные правила Тополова в
> машиночитаемый вид (измеримые признаки + таблица «признак → психотип»)
> для AI-модели, определяющей один из 13 психотипов по фотографии лица.

---

## 0. Краткое резюме метода

Каждый человек относится к одному из **13 психотипов**, расположенных на
**треугольнике A-B-C** (три вершины: **Лидер / Партнёр / Аналитик**). Базовые
«чистые» психотипы на вершинах: **АА-вс** (Лидер), **ВВ-ас** (Партнёр),
**СС-ав** (Аналитик). Остальные 10 — комбинации с двумя «вторыми»
компонентами.

Визуальная диагностика использует **5 ключевых признаков** геометрии лица
(порядок по убыванию силы сигнала):

1. **Форма лица** (пятиугольная ↔ окружность ↔ овал ↔ вытянутая)
2. **Форма носа** (треугольник книзу ↔ картошка ↔ узкий тонкий ↔ седлообразный)
3. **Ширина ротовой щели** (малая ↔ средняя ↔ большая)
4. **Улыбка Дюшена** (присутствует / отсутствует)
5. **Асимметрия лица** (есть / нет)

Правила ниже извлечены из 15 страниц оригинальной книги (страницы
36, 53, 66, 79, 92, 105, 126, 139, 152, 165, 178, 193, 206, 219, 231) и
сопоставлены с 13 психотипами.

## 1. Система координат треугольника A-B-C

```
                  A (Лидер) — красный
                  ▲
                 /│\
                / │ \
               /  │  \
              /   │   \
             /    │    \
            /     │     \
           /  ●   │   ●  \
          /   ●   │   ●   \
         /    ●   │   ●    \
        / ●●●  ●  │ ●  ●●●  \
       ▼──────────┼──────────▼
   С (Аналитик) ╳ В (Партнёр)
       синий         зелёный
```

Цвета психотипов:
- **Красный = Лидер** (A)
- **Зелёный = Партнёр** (B)
- **Синий = Аналитик** (C)

Все 13 психотипов ниже размещены в этом треугольнике; код из трёх букв
указывает на убывание силы трёх компонент. Например, `АА-вс` = А
доминирует абсолютно, B и C — слабые и примерно равные.

## 3. Измеримые признаки (feature definitions)

Каждый из 5 признаков ниже формализован в виде измеримой величины,
которую можно вычислить по фото (фас, нейтральное выражение, без
макияжа, разрешение ≥ 640 px по короткой стороне).

### 3.1. Форма лица (face_shape)

**Что измеряем.** Силуэт лица по 9 ключевым landmark'ам:
подбородок, обе челюсти, оба скуловых возвышения, оба виска, лоб.

**Алгоритм.**

1. Извлечь контур лица (MediaPipe FaceMesh → 468 точек → контур
   `face_oval` индексы 10, 338, 297, 332, 284, 251, 389, 356, 454, 323,
   361, 288, 397, 365, 379, 378, 400, 377, 152, 148, 176, 149, 150,
   136, 172, 58, 132, 93, 234, 127, 162, 21, 54, 103, 67, 109).
2. Измерить:
   - `face_height` = расстояние от подбородка (chin, landmark 152) до
     верхней точки лба (top, landmark 10).
   - `face_width_cheekbone` = расстояние между скуловыми точками
     (landmarks 234 и 454).
   - `face_width_jaw` = расстояние между углами нижней челюсти
     (landmarks 172 и 397).
   - `forehead_width` = расстояние между височными точками лба
     (landmarks 21 и 251).
3. Вычислить отношения:
   - `H_W_ratio = face_height / face_width_cheekbone`
   - `chin_sharpness = (face_width_cheekbone - face_width_jaw) / face_width_cheekbone`
   - `forehead_to_cheekbone = forehead_width / face_width_cheekbone`

**Классификация (5 классов).**

| Класс | Метки | Условия | Эталон |
|-------|-------|---------|--------|
| `pentagon` | пятиугольная, «лидерская» | H/W ∈ [1.15, 1.35], chin_sharpness ∈ [0.20, 0.35], forehead_to_cheekbone ∈ [0.85, 0.95] | Широкие скулы + узкий подбородок, выступающие скулы |
| `pentagon_round` | пятиугольная окружность, смесь | H/W ∈ [1.05, 1.20], chin_sharpness ∈ [0.10, 0.20] | Сглаженная пятиугольность, скруглённые углы |
| `circle` | окружность, «партнёрская» | H/W ∈ [1.00, 1.15], chin_sharpness ∈ [0.00, 0.10], forehead_to_cheekbone ≈ 1.0 | Широкое круглое лицо (тип «пиквик») |
| `oval` | овальная, переходная | H/W ∈ [1.20, 1.40], chin_sharpness ∈ [0.05, 0.20] | Овал, ближе круглый, чем вытянутый |
| `elongated_oval` | вытянутый овал, «аналитик» | H/W ∈ [1.40, 1.65], chin_sharpness ∈ [0.05, 0.15] | Узкое длинное лицо |
| `elongated_pentagon` | вытянутое + пятиугольное | H/W ∈ [1.35, 1.55], chin_sharpness ∈ [0.15, 0.25] | Длинное лицо с широким верхом и узким низом |

### 3.2. Форма носа (nose_shape)

**Что измеряем.** Профиль и ширину носа в трёх сечениях: переносица
(верх), средняя часть, ноздри (низ).

**Алгоритм.**

1. Взять landmarks носа: 1 (переносица), 4 (кончик), 5, 6 (крылья),
   45, 275 (внешние углы), 49, 279 (нижний край ноздрей).
2. Измерить:
   - `nose_length` = расстояние 1 → 4.
   - `nose_width_top` = расстояние между бровями у переносицы
     (landmarks 168 и 8) — ширина в верхней трети.
   - `nose_width_mid` = расстояние 168 → 8 (или по ближайшим
     landmark'ам костной части носа).
   - `nose_width_bottom` = расстояние 49 → 279.
3. Вычислить:
   - `taper_ratio = nose_width_bottom / nose_width_top`
   - `nose_total_ratio = nose_width_bottom / face_width_cheekbone`
   - `saddle_index = (nose_width_mid - 0.5 * (nose_width_top + nose_width_bottom)) / nose_length`

**Классификация (5 классов).**

| Класс | Метки | Условия | Эталон |
|-------|-------|---------|--------|
| `triangle_down` | треугольник книзу, расширяющийся | taper_ratio ∈ [1.4, 2.0], nose_total_ratio ∈ [0.18, 0.25], saddle_index ≤ 0 | Лидерский нос — узкий у переносицы, широкий у ноздрей |
| `triangle_saddle` | расширяется книзу + седлообразный | taper_ratio ∈ [1.2, 1.6], saddle_index > 0.05 | Переходная форма А-вс |
| `characteristic_partner` | «характерная» / картошка | taper_ratio ∈ [1.0, 1.3], nose_total_ratio ∈ [0.20, 0.28], округлый кончик | Партнёрский нос — мягкий, без выраженного расширения |
| `narrow_thin` | узкий тонкий, расширение у ноздрей | nose_total_ratio ∈ [0.12, 0.17], taper_ratio ∈ [1.3, 1.8] | Аналитик-ноc — минимальный по ширине и длине |
| `small_blend` | небольшой, смешанный | nose_total_ratio ∈ [0.14, 0.20], taper_ratio ∈ [1.0, 1.4] | Переходная форма (С-ав, ВСА) |

### 3.3. Ширина ротовой щели (mouth_width)

**Что измеряем.** Длина ротовой щели (левый угол — правый угол губ).

**Алгоритм.**

1. Взять landmarks рта: 61 (левый угол), 291 (правый угол),
   13 (верхняя губа центр), 14 (нижняя губа центр).
2. Измерить:
   - `mouth_width = dist(61, 291)`
   - `mouth_height = dist(13, 14)` (в нейтральном выражении ≈ 0,
     но при улыбке Дюшена — увеличивается).
   - `mouth_to_eye_ratio = mouth_width / dist(33, 263)` (между
     зрачками или внутренними углами глаз).

**Классификация (3 класса).**

| Класс | Метки | Условия | Эталон |
|-------|-------|---------|--------|
| `mouth_small` | малая ротовая щель | mouth_to_eye_ratio < 1.30 | Самый узкий рот — аналитик |
| `mouth_medium` | средняя | mouth_to_eye_ratio ∈ [1.30, 1.55] | Лидерский и переходные |
| `mouth_wide` | широкая / большая | mouth_to_eye_ratio ∈ [1.55, 1.80] | Партнёрский |
| `mouth_widest` | самая широкая | mouth_to_eye_ratio > 1.80 | Яркий Партнёр (ВВ-ас) |

### 3.4. Улыбка Дюшена (duchenne_smile)

**Что измеряем.** Наличие «настоящей» улыбки: сокращение
m. orbicularis oculi (морщинки у внешних углов глаз) + подъём
уголков губ.

**Алгоритм.**

1. Сравнить нейтральное фото и фото с улыбкой (или оценить
   «остаточную» активность мышц на нейтральном фото).
2. Измерить:
   - `eye_crinkle_index` = отношение площади морщин у внешних
     углов глаз (landmarks 33, 133, 160, 144, 158, 153, 263, 362,
     385, 387, 388, 466) к площади щеки.
   - `mouth_corner_lift` = вертикальное смещение landmark 61 и 291
     относительно нижнего века.
3. **Бинарный класс:**
   - `duchenne_present = true`, если `eye_crinkle_index > 0.20` И
     `mouth_corner_lift > 0.05 * face_height`.
   - `duchenne_present = false` иначе.

**Связь с психотипами (по Тополову):**

| Условие | Психотипический сигнал |
|---------|------------------------|
| Дюшен присутствует | **Партнёр** (ВВ-ас, ВАС, В-ас) |
| Дюшен отсутствует | **Аналитик** (СС-ав, С-ав) |
| Дюшен редко / спорадически | **Лидер** (АА-вс, А-вс, АСВ) |

### 3.5. Асимметрия лица (face_asymmetry)

**Что измеряем.** Степень отклонения левой половины лица от правой.

**Алгоритм.**

1. Зеркально отразить левую половину относительно вертикальной оси
   лица (через landmark 1 — переносицу и landmark 152 — подбородок).
2. Вычислить **IoU между половинами** и **среднюю попиксельную
   разницу landmark'ов** в зонах: глаза, брови, скулы, углы рта.
3. `asymmetry_score ∈ [0, 1]`.

**Бинарный класс:**

- `asymmetry_high = true`, если `asymmetry_score > 0.15` ИЛИ
  отклонение углов рта > 5% от ширины рта.
- `asymmetry_high = false` иначе.

**Связь с психотипами:**

| Условие | Психотипический сигнал |
|---------|------------------------|
| Асимметрия выражена | **Лидер** (особенно АА-вс, АСВ) |
| Асимметрия минимальна | **Аналитик / Партнёр** |

## 6. Эвристика разрешения конфликтов

Когда признаки противоречат друг другу (например, «лидерская»
форма лица, но широкая ротовая щель), приоритеты по убыванию силы
сигнала:

1. **Форма лица** (самый сильный маркер вершины треугольника).
2. **Форма носа** (второй по силе маркер).
3. **Ширина ротовой щели** (третий).
4. **Улыбка Дюшена** (сильный дискриминатор B vs C).
5. **Асимметрия** (сильный дискриминатор A vs B/C, особенно для АСВ).

**Алгоритм классификации:**

```
1. По форме лица определить вершину треугольника:
   - pentagon / pentagon_round / elongated_pentagon → A (Лидер)
   - circle / oval (ближе к круглому) → B (Партнёр)
   - elongated_oval → C (Аналитик)
2. По носу подтвердить вершину:
   - triangle_down (чёткий) → A
   - characteristic_partner (мягкий) → B
   - narrow_thin (тонкий) → C
3. По ротовой щели определить полюс внутри вершины:
   - mouth_widest / wide → партнёрская добавка (B ↑)
   - mouth_small → аналитическая добавка (C ↑)
   - mouth_medium → нейтрально (А ↑)
4. По Дюшен + асимметрии уточнить:
   - duchenne=true + asym=false → B
   - duchenne=false + asym=true → A (особенно АСВ)
   - duchenne=false + asym=false → C
```

**Формула итогового скоринга (для AI):**

```
score[psychotype] = Σ_i (w_i × match_i)
где w — вес признака (face=0.35, nose=0.30, mouth=0.20, duchenne=0.10, asym=0.05)
    match_i ∈ {0, 1, 2, 3} — совпадение с каноном (см. таблицу 4.x)
psychotype_pred = argmax(score)
```

## 9. Известные ограничения и предостережения

1. **Источник — описание, не алгоритм.** Оригинальные правила
   Тополова — нарративные («почти пятиугольная», «расширяется книзу
   ближе к ноздрям»). Метрики выше — **экспертная формализация** на
   основе текста, не авторский алгоритм.
2. **Границы классов — рабочие.** Числовые пороги (H/W ratio и пр.)
   подобраны на основе фотографий знаменитостей из книги. На
   независимой выборке их нужно калибровать.
3. **Страница 231 (СВА)** формально выходит за 13 психотипов. В
   коммерческом продукте можно либо (a) считать СВА отдельным
   14-м типом, либо (b) трактовать его как СС-ав + чувствующая
   добавка.
4. **Асимметрия** по книге — признак Лидера вообще (стр. 79), но
   максимально характерен для АСВ.
5. **Улыбка Дюшена** — стабильный дискриминатор B vs C. У Аналитиков
   практически не встречается (стр. 193).
