# Аудит — сервис аудита безопасности интернет-магазинов

Рабочее название: **Аудит** (утверждено 03.08.2026)
Статус: **исследование** (гипотеза, фаза 0)

## Встреча 08-09.08.2026

Сергей встречается по поводу Аудита (завтра-послезавтра от 07.08). Состав/цель встречи уточнить. Материалы готовы: otchet-audit-bezopasnosti-magazinov-152fz.md, techosmotr-vulnerability-scanner-report.md, security-audit-market-report-ru.md (в /root). Возможна подготовка one-pager для встречи.

## Идея

Автоматизированный сервис аудита уязвимостей для **небольших интернет-магазинов РФ**, которые уходят с Ozon/Wildberries на собственные сайты. Позиционирование: «техосмотр магазина» + проверка соответствия 152-ФЗ. Отчёт на человеческом русском, для не-технаря.

## Источник идеи

03.08.2026: информация от знакомых Сергея (из третьих рук): услуга востребована, заказов много, но текущие исполнители делают плохо, клиенты не возвращаются. Реальных заказчиков пока нет.

## Ключевые гипотезы

- Целевая аудитория: владельцы малых магазинов (WordPress/WooCommerce, 1С-Битрикс, Tilda, InSales)
- Крючок продажи: 152-ФЗ и утечки клиентских данных (штрафы с конца 2024 — до миллионов руб)
- Цена: 5-15 тыс руб разовый отчёт, подписка на мониторинг 2-3 тыс/мес
- Слабость конкурентов = качество и сервис. Ниша «дёшево, качественно, по-человечески» почти пустая

## Юридические рамки

- Сканировать ТОЛЬКО с письменного согласия владельца сайта (иначе ст. 272 УК РФ)
- Вопрос лицензирования ФСТЭК — в исследовании
- Режим: non-intrusive (безопасный аудит без эксплуатации уязвимостей)

## Бэклог / заметки

- **Инфраструктура (решение 07.08):** Лёгкий аудит (CMS-версии, SSL, заголовки, 152-ФЗ) — с текущего Hetzner 8GB, ничего нового не нужно. Активный пентест (Nuclei, Nmap, sqlmap) — только с отдельного дешёвого VPS (~4-5€/мес, Hetzner) для защиты IP-репутации основного сервера (Triangula, fravart.ru, почта). Триггер покупки: первый реальный заказ на активный аудит.
- **reverse-skill** (github.com/zhaoxuya520/reverse-skill, 20k⭐, MIT): роутер навыков для реверс-инжиниринга/пентеста (APK, бинарники, CTF). ❌ как цельный пакет (реверс/APK/CTF — не наш кейс, тяжёлый тулкит не поднять), но 07.08.2026 **проработан частично**: полезные куски — scope-контракт (письменное разрешение до любых действий), шаблон findings, гайд Nuclei 2026, recon-пайплайн с Cloudflare-нюансом, JWT/REST-методология — вытащены в `/opt/audit-kit/` (80 КБ, 12 файлов). Это методологическая база для активного аудита.
- **TencentDB-Agent-Memory** (github.com/TencentCloud/TencentDB-Agent-Memory, MIT): плагин слоистой памяти для агентов, есть поддержка Hermes. Сейчас не нужен — своя память работает. Вернуться, если «Аудит» вырастет в долгоиграющего агента с тоннами логов сканеров.
