### 1. Hero с «исследуемым образцом» и сеткой
- Заменил центрированный hero на **двухколоночный**: текст слева, справа — портрет в рамке (`specimen-frame`, лёгкий наклон).

- **Измерительные линии**: линия глаз + вертикальная средняя линия («трети») — пунктиром.
- **Сканлайн** — бегущая коралловая полоса.
- **HUD-метки** по углам (JetBrains Mono): «478 landmarks», «Δ eye-line · level», «frontal · clean», «study № 03».

### 2. Мобильное меню-бутерброд (по просьбе Сергея)
- Проблема: на узком экране пункты навигации сползали/переносились.
- Решение: кнопка ☰ (`#navToggle`, 3 полоски → анимация в ✕), видна на ≤820px.
- Меню выпадает **панелью вниз** на всю ширину: тёмный блюр-фон, тень, плавное появление 0.25s.
- Пункты крупные (16px) с разделителями; «Begin a reading» — коралловая кнопка на всю ширину.
- Логика (`initNavToggle` в script.js): тап по ссылке закрывает, Escape закрывает, ресайз>820px сбрасывает, ARIA-атрибуты.
- Удалил устаревшие правила `.nav { gap/font-size }` из media ≤640px и ≤420px — мешали панели.
- Уменьшил hero top-padding на мобильных (110px → 56px).
