# Методика Тополова: скоринг-движок + PDF-отчёты + web-форма

Закрыт контур: из Excel-формул `64-z.xlsx` → работающий сервис генерации отчётов по психотипам. Всё в `/root/face_method_kb/`.

## Что сделано

### 1. Скоринг-движок `scoring.py`
- 41 вопрос × ответ 1–10 → суммы шкал A/B/C → проценты → паттерн `A-B-C` → психотип
- Точное воспроизведение Excel: 64 паттерна, пороги для «чистых» типов (А>44 и т.п.), пограничные случаи
- Достоверность по α-Кронбаха (17 контрольных ABS-формул), баг с abs() исправлен
- Маппинг кодов: А(n),А-вс(n) → АА-вс (Лидер) · В(n),В-ас(n) → ВВ-ас (Партнёр) · С(n),С-ав(n) → СС-ав (Аналитик) · АВС, АСВ, ВАС, ВСА, САВ, СВА, авс

### 2. Генератор отчёта `generate_report.py`
- HTML → PDF (3 стр. А4) через Playwright
- Содержимое: шкалы с диаграммами, характеристика психотипа, тип личности (6) / мышления (5), 40 индикаторов, деструкторы, стили руководства (4)
- Контент всех 16 психотипов — `psychotype_content.json` (извлечён из книги; есть артефакты переносов, у «авс» стили без оценок)

### 3. Web-форма `web_app.py` (FastAPI, порт 8090)
- `GET /` — 41 слайдер (ответы 1–10, живое значение), `POST /report` → PDF
- Питфолл: Playwright Sync API нельзя в asyncio → `asyncio.to_thread`; `generate_report.scoring` не работает → `from scoring import QUESTIONS`
- Сервер запущен, протестирован (GET 200, POST → PDF)

### 4. Проверка на реальных прогонах
- Профиль `35-28-37` → **САВ «Действующий аналитик»**, достоверность 85.3% (средняя)
- Лидерский профиль `45-25-30` → **АА-вс «Лидер»**, достоверность 76.5%
- Все 5 / все 10 / случайные → работают, пограничный тип обрабатывается

```bash

python3 generate_report.py --name "ФИО" --answers "41 число через запятую" --out /tmp/report.pdf
PORT=8090 python3 web_app.py
```
