## Обзоры инструментов (Сергей кидал ссылки)

1. **firecrawl/pdf-inspector** — Rust-библиотека: классификация PDF (текст/скан) + извлечение в Markdown с таблицами. Быстрая (200 док/0.5с). **Отложено** — пригодится, когда начнут приходить проекты КСП в PDF (спецификации, сметы). Поставить: pip install pdf-inspector, прогнать на реальных документах.
2. **langflow-ai/langflow** — визуальный конструктор AI-агентов. **Не нужно** — дублирует Hermes + n8n.
3. **browser-use** — «руки для ИИ в браузере». **Не нужно** — у Hermes уже встроен браузер (navigate/click/type/vision).
4. **insights-lm-public** — open-source NotebookLM (чат с документами + аудио-саммари, Supabase+n8n+React). **Не нужно** — умеем сами (search_kb + TTS), лишняя инфраструктура. Сценарий «свой NotebookLM для клиентов» — можно собрать на n8n + Alibaba + TTS без Supabase, но это отдельный продукт.
5. **Коннект с NotebookLM** — **не нужно**: проектная документация КСП не должна лежать в облаке Google; всё нужное уже локально.
