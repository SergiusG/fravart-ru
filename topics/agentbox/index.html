    AgentBox — проект¶

    Статус: MVP запущен 2026-08-15, бот работает в Telegram, web-лендинг живой.

    Дизайн-система¶

    Палитра (финальная, 16.08.2026): Telegram-стиль — узнаваемый, ассоциируется с ботом @zdes_agentbox_bot. - --bg: #0a1628 (глубокий navy) - --bg-alt: #17212b (стандартный telegram-bg) - --bg-card: #17212b - --text: #e8eef5 (paper) - --primary: #1f88c5 (telegram-blue) — главный акцент - --primary-light: #2eaadc (light blue) - --accent: #ff8c42 (telegram-orange) — бейджи/«В разработке»

    Идея: «это вон тот бот в Телеграме». Пользователь видит лендинг и сразу узнаёт продукт. Сильная ассоциация.

    Итерации, которые не зашли (для истории): 1. Indigo + amber (стандартный SaaS) 2. Тёплая природная (мята/кремовый/персик) 3. Gorgonzola Blue + Autumn Glory 4. Teal фон + Deep Azure текст (плашки сливались) 5. Монохром + бирюзовый (#00d4aa) — красиво, но не узнаваемо 6. Терракота + графит — слишком ремесленно для D2C

    Что это¶

    Коробочный ИИ-помощник для российского пользователя. D2C. Telegram + web + Mini App. Покупаешь подписку → выбираешь шаблон → за 30-60 сек получаешь готовый результат. Без VPN, без промпт-инжиниринга.

    Архитектура¶

    Frontend (Cloudflare Pages)¶

    • Vanilla JS, без билда — работает без npm install
    • 7 шаблонов-карточек → модалка-форма → результат
    • API URL хардкод: https://agentbox-api.senega.workers.dev

    Backend (Cloudflare Worker)¶

    • TypeScript → esbuild через wrangler
    • Endpoints:
    • GET /health — health check
    • GET /templates/ — список шаблонов
    • GET /templates/{id} — детали с полями
    • POST /templates/{id}/run — AI-генерация
    • POST /tg/webhook — Telegram updates
    • GET /tg/set_webhook — одноразовая установка webhook
    • Секреты через wrangler secret put:
    • ALIBABA_API_KEY — Alibaba Token Plan
    • TELEGRAM_BOT_TOKEN — @zdes_agentbox_bot
    • Env vars в wrangler.toml:
    • ALIBABASE_URL — https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1

    AI-роутер (в Worker)¶

    • Семантический выбор модели по типу задачи (text_simple, text_complex, text_ru)
    • Цепочка фолбэка: qwen3.7-plus → glm-5.2 → qwen3.6-flash → deepseek-v4-flash
    • Подсчёт стоимости в USD по token'ам

    Telegram-бот¶

    • FSM через in-memory Map (теряется при редеплое, для прода → D1)
    • Команды: /start, /help, /cancel, /<template_id>
    • 7 шаблонов с conversation flow (пошаговый ввод полей)
    • Inline-кнопка «🚀 Открыть приложение» → Mini App → web-лендинг

    Ключевые решения (что делали и почему)¶

    1. Cloudflare Workers вместо Python backend¶

    • Бесплатно (100k req/day)
    • Без отдельного сервера
    • Секреты через wrangler secret
    • Деплой за 5 сек
    • Прямая маршрутизация на наш домен

    2. Alibaba Token Plan как AI-провайдер¶

    • Уже есть ключ в /root/.hermes/.env
    • Совместимый OpenAI API endpoint в Singapore
    • qwen3.7-plus — основная, qwen3.8-max — для сложных задач
    • Фолбэк-цепочка защищает от 429 quota exceeded

    3. FSM в in-memory Map (не D1)¶

    • Для MVP прототипа достаточно
    • На прода нужен D1/KV, иначе сессии теряются при редеплое

    4. Vanilla JS frontend без React¶

    • Деплой одной командой wrangler pages deploy
    • Без билда, без зависимостей
    • 200 строк JS достаточно для D2C UI

    5. Telegram polling как страховка¶

    • Webhook возвращал 200, но юзер не получал ответ
    • Временный polling через /tmp/agentbox_poll.py забрал update'ы
    • После отладки вернули webhook (экономит квоту Worker'а)
    • Урок: для отладки Worker'а лучше polling + log scraping
