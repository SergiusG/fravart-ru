    Face Method Startup Playbook — итог 26 июля 2026¶

    Дата: 2026-07-26, воскресенье, МСК Автор аналитической записки: Hermes по поручению Сергея Источник: синтез PDF-материалов Тополова + 17 публикаций на aftershock.news + 3 субагентских отчёта (EN-конкуренты / юр. ограничения / азиатский рынок)

    Главная мысль (TL;DR)¶

    У нас есть сильный метод без работающего продукта. Задача — превратить авторскую методику (книги + 16 психотипов + визуальная диагностика) в англоязычный AI-сервис с правильным позиционированием, обходящим юридические риски. На рынке EN — 10 конкурентов, но никто не закрывает нишу «career / professional inclinations by face» для B2C entertainment. Окно открыто.

    Топ-3 действия по приоритету:

    1. Закрыть IP-риск — проверить патенты по «Тополов» (ФИПС / USPTO) за 30 минут
    2. Запустить MVP как «character archetype discovery» (не «professional analysis») — это снимает EU AI Act, FTC, EEOC
    3. Сделать первую English-страницу лендинга с двумя режимами: free entertainment + premium «career exploration» (с geofencing и consent-флоу для IL/TX/EU)

    Что у нас есть (asset inventory)¶

    A. Авторский метод (Тополов В.) — собрано¶

    • 3 книги Ridero (2020-2024): «Мальчишки», «Потенциал руководителя», «Читаем мысли клиента!»
    • Excel-тест 41 вопрос с привязкой к 3 шкалам (A=Лидер/красный, B=Партнёр/зелёный, C=Аналитик/синий)
    • 16 психотипов в 3 доминантах + 3 «гибрида» (жёлтый, фиолетовый, авс-посредник)
    • Визуальные правила AI-ready (5 признаков → 13 классов; правила в face_visual_rules.json)
    • 17 публикаций на aftershock.news + разборы известных людей (Трамп, Байден, Мамонов, Агузарова и др.)
    • 3 работающих Telegram-бота автора: @LeaderProfile_bot, @PersonaPhotoType_bot, @SellerProfile_bot
    • Коммерческий сайт potencial-pro.ru
    • Telegram-канал @topologialichnosti

    B. Исследование рынка (3 субагента) — готово¶

    • Конкуренты EN (отчёт 30 КБ): 10 игроков в 4 сегментах. Свободная ниша — «career-fit по фото для B2C entertainment»
    • Юридический меморандум (40 КБ, 535 строк): критические риски EU AI Act Art.5(1)(f), Illinois BIPA, Texas CUBI, FTC AI-washing, EEOC Title VII
    • Азиатский маркетинг (75 КБ, 1095 строк): культурные коды CN/JP/KR/TW + 7 архетипов + 7 виральных форматов + 12-недельный план валидации

    Стратегическое позиционирование (решает всё)¶

    Главный разворот: «Entertainment, не prediction»¶

    Было (рискованно): «AI-сервис по определению способностей человека по фото» Стало (безопасно): «Discover your character archetype» — развлечение / самопознание

    Юр. зона Риск при старой формулировке При новой формулировке
    EU AI Act Art.5(1)(f) ❌ Hard-prohibited (€35M / 7% оборота) ✅ Нет workplace inference
    Illinois BIPA ❌ Class-action $1-5K/скан ⚠️ Остаётся — нужен geofence IL
    Texas CUBI ⚠️ $1.4B Meta settlement ⚠️ Остаётся — нужен geofence TX или consent
    FTC AI-washing ❌ Нет научной базы ✅ Развлечение не требует substantiation
    EEOC Title VII ❌ Disparate impact ✅ Нет HR-использования

    Конкурентная ниша (что мы заняли)¶

    Свободная позиция на карте: - B2C + Entertainment + Career-adjacent + EN - Цена: $9.99 за отчёт (как MeByFace) или freemium - Формат: сразу 16 психотипов (у MeByFace только 4), с визуальной диагностикой (большинство конкурентов — текстовый)

    Прямые референсы в нише: - MeByFace (€9.99/dim, текст-only, не face-priority) - Facework (career audition, но мёртвый трафик) - Face Astro (top-3 career — есть конкурент, но слабый)

    Ключевое преимущество: 16 психотипов (richer) + визуальный + опросный (dual-channel) + авторская методология с эмпирикой по продажам (ни у кого из конкурентов)

    Технический MVP — что нужно для запуска¶

    Backend¶

    • CV pipeline: MediaPipe FaceMesh → 468 landmarks → 12 метрик (5 признаков из 13 классов)
    • Rule engine: JSON с 16 правилами (face_visual_rules.json) + пороги
    • Scoring: анфас-фото → веса 3 шкал A/B/C → 1 из 16 психотипов
    • LLM layer: Anthropic Claude или GPT-4o для нарратива отчёта
    • Frontend: Single-page React + Stripe для paid tier

    Контент¶

    • 16 описаний психотипов (EN) — уже есть на базе переводов из boys.txt
    • Disclaimer на каждом шаге (entertainment, not diagnostic)
    • Geofencing для IL/TX/EU (в paid tier)

    Время до MVP¶

    • Неделя 1: лендинг + дисклеймер + простая форма загрузки фото
    • Неделя 2: визуальный пайплайн + rule engine (тестирование на 50 фото знаменитостей из публикаций Тополова)
    • Неделя 3: LLM-нарративы + Stripe + paywall
    • Неделя 4: A/B-тест 5 лендингов + первый запуск
