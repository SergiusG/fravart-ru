    Buzz (block/buzz) — референс архитектуры для AgentBox¶

    Заметка от 16.08.2026. Источник: клон /root/projects/buzz (Apache 2.0, Block Inc, 27.5k★). Цель: взять паттерны, отбросить масштаб и Nostr. AgentBox — Cloudflare Worker + Pages, lean MVP.

    Что такое Buzz в одном абзаце¶

    Self-hosted командный мессенджер поверх Nostr (NIP-01 wire format). Каждое действие (сообщение, реакция, шаг workflow, аудио-фрейм) — подписанное Nostr-kind событие. Relay (Axum + Rust) — единый источник истины: WebSocket + узкий HTTP. Люди и агенты — равноправные участники с одним типом идентичности (secp256k1 keypair). Агенты подключаются через ACP-harness (buzz-acp), который спавнит сабагентов по stdio (JSON-RPC 2.0), слушает @mentions и отправляет ответы.

    Главные идеи для нас (что переносить)¶

    Идея Buzz Что это Применение в AgentBox
    Единое событие = единый формат Любая фича = новый kind без поломки старых клиентов У нас: каждый шаблон задачи имеет свой тип ответа/состояния, единый JSON в Telegram Mini App
    Agent как first-class Агент имеет pubkey, историю, репутацию — такие же как человек У нас: агент-бот в Telegram = собеседник наравне с Сергеем, видит историю диалога
    Workflow YAML-as-code .buzz/workflows/*.yaml, триггеры (message_posted, schedule, webhook), действия (send_message, request_approval, call_webhook) Отложено в бэклог AgentBox — после MVP. Делать шаблоны по событиям (новый заказ → отправить КП)
    Branch-as-room / Project-as-channel Один проект = один канал со всей историей (сообщения, файлы, решения) У нас: «шаблон как комната с историей» — каждый запуск задачи = тред со всеми артефактами
    ACP harness buzz-acp подписывается на @mentions, спавнит сабагента, шлёт prompt через stdio ACP У нас уже есть Hermes + cron, не нужен. Но паттерн «слушай события → вызывай агента» — наш cron-watchdog (76fc966fc7f5)
    API-токены с scopes 14 скоупов (MessagesRead, FilesWrite, ...) Прямо сейчас не нужно, но когда появится публичный API AgentBox — брать как образец
    Audit hash-chain SHA-256 цепочка всех действий, tamper-evident Не нужно для MVP. Если AgentBox станет корпоративным — критично для 152-ФЗ
    Connection semaphore + slow-client grace Лимит коннектов, отключение медленных клиентов после 3 полных буферов Пригодится если Cloudflare Worker упирается в concurrent лимиты

    Что НЕ переносим¶

    Buzz Почему не нужно
    Rust relay Overkill — у нас Worker + Pages + KV/D1
    Nostr-протокол Нет нужды в федерации. У нас свой auth (Cloudflare Access)
    secp256k1 идентичности Сложно для пользователя. Достаточно Telegram ID + email
    S3/Postgres на своём сервере Cloudflare R2 + D1 покрывают
    Мобильное приложение (Flutter) Telegram Mini App достаточно
    Huddle audio (WebSocket Opus) Telegram уже даёт голосовые

    Архитектурные принципы, которые стоит утащить как есть¶

    Из VISION_AGENT.md и ARCHITECTURE.md:

    1. «Minimal. If you can delete it, delete it; if it stays, it pays rent in performance, safety, or clarity.» — у AgentBox уже так, продолжать
    2. «Composability through standards» — ACP и MCP дают совместимость. У нас: Telegram Bot API + Cloudflare API, не плодим свои протоколы
    3. «The relay is the single source of truth» — у нас: Cloudflare Worker = state-of-truth, Telegram/MAX/сайт = клиенты
    4. «Zero unsafe. Bounded everything. Graceful degradation.» — agent harness Buzz рассчитан на запуск 10 экземпляров параллельно без overhead. Наш принцип тот же
    5. «Honest: prompt LLM, execute tool calls, repeat. When context fills, summarize and continue.» — у нас так и есть (Hermes), но саммаризация контекста пока не реализована — это пункт в бэклоге

    Конкретные действия для AgentBox (что я могу сделать прямо сейчас)¶

    # Что Зачем Сложность
    1 Контекст задачи как «комната» — каждый запуск шаблона получает room_id, все сообщения и артефакты привязаны к нему Имитация branch-as-room без Nostr 1 день
    2 buzz-cli JSON in/out для нашего AgentBot API — отдельный эндпоинт /agent/json с тем же контрактом что и Telegram webhook Совместимость со внешними ИИ-агентами 2 дня
    3 Скоупы для API-токенов (templates:read, templates:write, runs:read, runs:write) Когда появятся интеграции 2 дня
    4 Audit log — простая append-only таблица в D1 с hash-chain (можно упростить: prev_hash + event_hash) Базовый для 152-ФЗ когда дойдёт до прод 3 дня

    Топ-3 паттерна которые точно стоит скопировать дословно¶

    1. branch_kind_index для подписок — O(1) фильтрация событий по (channel_id, kind). У нас в Worker: для каждого пользователя индекс {chat_id: [template_ids]} в KV
    2. handler_semaphore capacity 1024 — лимит concurrent обработки. У нас: Cloudflare Workers даёт 30 subrequests + 30 concurrent connections, считать надо
    3. ON CONFLICT DO NOTHING для идемпотентности — Telegram любит дублировать webhook'и, мы уже страдаем. Сохранять event_id (Telegram update_id) и не обрабатывать дважды

    Вывод одной строкой¶

    Buzz — это «как делать коммуникационную платформу с агентами, когда деньги и время есть». AgentBox — это «как делать то же самое на коленке с Cloudflare за неделю». Переносим принципы, отбрасываем масштаб.
