    • Сделано в этой сессии:
    • Бот поднят, работает вживую.

    2. Alibaba квота — разобрано (исходные данные)¶

    • План: Standard $18/мес (не Lite, не Pro). Текущая 7-day квота израсходована на 61,62% за 1,5 дня (~41%/день). Остаток ~38% → риск упора в недельный лимит завтра-послезавтра.
    • Подписка Alibaba заканчивается через 9 дней. Есть риск 4 дня «без Alibaba» + 3 после сброса.
    • Важный урок (учтён!): «дешёвые токены» (cached input, 96% кэша у deepseek-v4-flash) — скидка уже ВСТРОЕНА в процент квоты (61,62%). Доп. запаса из них НЕ извлекается. Сырые токены (36,69M за 5ч) ≠ квота. Не «успокаивать» себя этой дешёвостью.
    • Про скидку непик: Alibaba даёт скидку на кредиты в непиковые часы 22:00–08:00 по Пекину (вост. аккаунт). Учитывать при тяжёлых генерациях.
    • Точные лимиты по окнам через API НЕ получить (sk-sp- key, compatible-mode не отдаёт квоту). CLI bl установлен (bl auth login --console --console-site international), но OAuth-redirect на 127.0.0.1 не проходит с телефона — нужен SSH-туннель с компа (ssh -L <port>:127.0.0.1:<port> root@65.21.154.45). Либо смотреть вручную в консоли (modelstudio.console.alibabacloud.com, в Яндекс-браузере — Chrome с китайскими сайтами съезжает).
