    11.08 — Аудит triangula.app (собственный сайт, пример отчёта)¶

    Прогнал triangula.app по 3 уровням (владелец — Сергей, глубокое сканирование без поломок):

    Критичные (2): 1. /api/pdf отдаёт платный отчёт БЕЗ проверки лицензии — пустой/отсутствующий license_key → PDF уходит полностью. Неверный непустой ключ отклоняется (проверка только если ключ заполнен). Продукт $14.99 — защита оплаты не работает. 2. Проверка лицензии закомментирована в sendReportToEmail («report sends freely») — /api/send-report шлёт отчёт на email без ключа.

    Средние (1): нет заголовков безопасности вообще (7 из 7 отсутствуют: CSP, X-Frame-Options, HSTS...)

    Низкие (2): /api/health раскрывает версию и структуру; слабая валидация типов в /api/reading.

    Хорошо: CORS ограничен своим origin, скрытые пути закрыты (403/404), секретов в коде нет, API валидирует поля, TLS от Google валиден, robots/sitemap на месте.

    Файлы: Пример_отчета_Аудит_triangula_app.pdf (в prototype/, рядом с neksora-отчётом). Оба отчёта — продаваемые образцы для «Аудита».
