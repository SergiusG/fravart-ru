    15.08.2026 — MiniMax Token Plan: точный статус квот¶

    Контекст¶

    Сергей попросил проверить, что реально работает в MiniMax Token Plan и какие квоты. Проверил утром 15.08 в 07:33 МСК (04:33 UTC).

    Сводный статус (15.08 07:33 МСК)¶

    Модель Статус Детали
    Text (MiniMax-M3) ✅ работает chat completions OK, usage ~200 tokens на тест
    TTS (speech-2.6-turbo, onyx) ✅ работает ~30 сек на 1 ролик (голос MiniMax)
    Music (music-2.6) ✅ работает ~33 сек на 5 сек музыки
    Video (Hailuo-2.3) ❌ заблокирован код 2067: «upgrade your plan or buy credits and turn on auto consumption»

    Код ошибки video (точно)¶

    {
  "task_id": "",
  "base_resp": {
    "status_code": 2067,
    "status_msg": "The Token Plan usage limit has been reached. To avoid interruption, please upgrade your plan or buy credits and turn on auto consumption."
  }
}

    Вчера (14.08 18:30 МСК) был код 2056. Сегодня — 2067. Разница — 2056 был общий «Token Plan usage limit», 2067 — это «usage limit reached, time to upgrade/buy credits».

    Вывод про тип окна¶

    Video НЕ в 5-часовом окне. С 14.08 18:30 МСК до 15.08 07:33 МСК прошло ~13 часов — если бы это было 5h-окно, оно сбросилось бы минимум 2 раза. Не сбросилось.

    Это значит либо недельное, либо месячное окно (как у Alibaba token-plan, по наблюдениям 08.08.26).

    Text / TTS / Music продолжают работать — значит их окна не выбраны, либо другие окна.

    Что делать с видео¶

    Опции (по документации): 1. Upgrade Plan — $50/мес Max (вместо $20/мес Plus). Больше квот, без автоматического списания. 2. Buy Credits — $5 / $25 / $100. Покрывают overflow после основной квоты. 3. Turn on auto consumption — после покупки credits они автоматически списываются при исчерпании основной квоты.

    Правило Сергея: «ИИ: не регистрироваться/пополнять». Сергей решает — платить или обходиться без видео через MiniMax.

    Альтернатива для Triangula (уже работает)¶

    Alibaba wan2.7-image (token-plan жив, неделя сбросилась 14.08 в 17:00 UTC, сейчас подписка активна): - 5 PNG-картинок → ffmpeg concat → mp4 - Использовали в #17, #18 Triangula - Качество: премиум (минималистичные силуэты с glowing точками) - Стоимость: $0 (в подписке) - Время: ~3 минуты на ролик

    Этого достаточно для текущего pipeline Triangula. Видео через Hailuo — это бонус, не критично.

    Что с music-2.6¶

    Работает, но медленно: 33 сек на 5 сек музыки. Это для batched генерации неудобно. Решение: - Не использовать MiniMax music в основном цикле - Продолжать использовать готовый eleven_music_bh.mp3 (уже на Drive) - Если нужна новая музыка — через MiniMax music-2.6 разово, не в цикле

    Рекомендация¶

    1. TTS через MiniMax onyx — оставить как есть, основной голос
    2. Видео через MiniMax Hailuo — заблокировано, не планировать
    3. Визуал для Triangula — продолжать через Alibaba wan2.7-image (PNG-картинки + ffmpeg)
    4. Music — оставить готовый трек, MiniMax music как запасной вариант

    Что НЕ нужно делать¶

    • Не проверять video API чаще 1 раза в день (status не изменится без upgrade)
    • Не пытаться обходить quota через retry (получим тот же 2067)
    • Не искать альтернативные endpoints (все /v1/user, /v1/account → 404)
